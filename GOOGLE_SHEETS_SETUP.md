# 📊 Настройка синхронизации с Google Sheets

Это пошаговый гайд по подключению бота к Google Таблицам.
После настройки бот будет **автоматически обновлять** отчёты в облаке при каждой сдаче отчёта сотрудником.

---

## Шаг 1 — Создание проекта в Google Cloud

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. В верхней панели нажмите **«Select a project»** → **«NEW PROJECT»**.
3. Введите любое название, например `ph-time-bot`. Нажмите **«Create»**.
4. Убедитесь, что новый проект **выбран** в верхней панели.

---

## Шаг 2 — Включение нужных API

1. В левом меню выберите **«APIs & Services»** → **«Library»**.
2. Найдите и включите **два** API (для каждого нажмите «Enable»):
   - **Google Sheets API**
   - **Google Drive API**

---

## Шаг 3 — Создание сервисного аккаунта

1. Перейдите в **«APIs & Services»** → **«Credentials»**.
2. Нажмите **«+ CREATE CREDENTIALS»** → **«Service account»**.
3. Заполните поля:
   - **Service account name**: `ph-time-bot` (или любое)
   - **Service account ID**: заполнится автоматически
4. Нажмите **«CREATE AND CONTINUE»** → **«DONE»** (роли можно пропустить).
5. В списке сервисных аккаунтов нажмите на только что созданный.
6. Перейдите на вкладку **«Keys»** → **«ADD KEY»** → **«Create new key»**.
7. Выберите формат **JSON** → нажмите **«CREATE»**.
8. Файл автоматически скачается (например `ph-time-bot-xxxxxxxx.json`).

---

## Шаг 4 — Размещение ключа на сервере

Переименуйте скачанный файл в `service_account.json` и положите его в **корень проекта** рядом с `docker-compose.yml`:

```
ph-time-tg/
├── docker-compose.yml
├── .env
├── service_account.json   ← сюда
└── bot/
    └── ...
```

> ⚠️ **ВАЖНО**: Никогда не коммитьте этот файл в git!
> Проверьте, что `service_account.json` есть в `.gitignore`.

Добавьте в `.gitignore` если ещё нет:
```
service_account.json
```

---

## Шаг 5 — Создание Google Таблицы

1. Откройте [Google Таблицы](https://sheets.google.com/) и создайте новую таблицу.
2. Дайте ей название, например: **«PH Time — Отчёты»**.
3. Скопируйте **ID таблицы** из адресной строки браузера:
   ```
   https://docs.google.com/spreadsheets/d/  ВОТ_ЭТО_И_ЕСТЬ_ID  /edit
   ```
   Пример ID: `1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms`

---

## Шаг 6 — Выдача доступа к таблице

1. Откройте скачанный `service_account.json` любым редактором.
2. Найдите строку `"client_email"` — скопируйте адрес вида:
   ```
   ph-time-bot@ph-time-bot-xxxxxxx.iam.gserviceaccount.com
   ```
3. В Google Таблице нажмите **«Поделиться»** (кнопка справа вверху).
4. Вставьте этот email и выдайте роль **«Редактор»**.
5. Нажмите **«Отправить»**.

---

## Шаг 7 — Настройка `.env`

Откройте файл `.env` и заполните три строки:

```env
# Включить интеграцию с Google Sheets
USE_GOOGLE_SHEETS=True

# ID вашей Google Таблицы (из шага 5)
GOOGLE_SHEETS_SPREADSHEET_ID=1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms

# Путь к файлу ключей (относительно корня проекта)
GOOGLE_SERVICE_ACCOUNT_FILE=service_account.json
```

---

## Шаг 8 — Установка зависимостей и перезапуск

Если используете Docker:
```bash
docker-compose down
docker-compose up -d --build
```

Если запускаете локально:
```bash
pip install -r requirements.txt
python -m bot
```

---

## ✅ Проверка работы

1. Зайдите в бота и нажмите **«⚙️ Админ-панель»** → **«📊 Отчёты»**.
2. Нажмите кнопку **«🔄 Синхронизировать Google»**.
3. Через 2–5 секунд бот пришлёт сообщение: `✅ Синхронизация успешно завершена!`
4. Откройте Google Таблицу — там должны появиться вкладки вида `Гомель (Май 2026)`.

Если синхронизация не работает — проверьте логи:
```bash
docker-compose logs bot --tail=50
```

---

## 🗂 Структура таблицы

Бот автоматически создаёт **отдельный лист** для каждого города и месяца:

| Лист              | Содержимое                              |
|-------------------|-----------------------------------------|
| `Гомель (Май 2026)` | Календарь отчётов по Гомелю за май   |
| `Минск (Май 2026)`  | Календарь отчётов по Минску за май   |
| `Гродно (Июнь 2026)`| Автоматически создастся в июне       |

Старые листы **не удаляются** — вся история хранится в одной таблице.

---

## ❌ Как отключить синхронизацию

Если нужно временно отключить Google Sheets — просто измените в `.env`:
```env
USE_GOOGLE_SHEETS=False
```
И перезапустите бота. Excel-экспорт по запросу продолжит работать как обычно.
